# Sword — Аналитическая платформа мониторинга трендов TikTok и Instagram Reels

**"Sword"** — это клиентское высокопроизводительное веб-приложение для анализа и визуализации вирусных коротких видео (Reels / Shorts) в режиме реального времени.

## Стек технологий
- **Vue 3** (Composition API, `<script setup lang="ts">`)
- **Pinia** (Реактивное хранилище состояния)
- **Vite** (Сборщик и Dev-сервер)
- **Yarn** (Пакетный менеджер)
- **Tailwind CSS** (Кастомная тёмная неоновая палитра Sword)
- **Lucide Icons** (`lucide-vue-next`)
- **Экспорт отчетов**:
  - `docx` (Microsoft Word .docx)
  - `jspdf` + `jspdf-autotable` (PDF формат)
  - `file-saver` (Сохранение файлов в браузере)

## Ключевой функционал

1. **Бессерверное автообновление в реальном времени (Serverless Live Engine)**:
   - Встроенный таймер обратного отсчета с интервалом обновления каждые 2 минуты.
   - Динамический пересчет вирусных метрик (просмотры, лайки, шеринги, ER%, темп роста Velocity).
   - Индикаторы изменения ранга в топе (▲ Вверх, ▼ Вниз, NEW).
   - Возможность ручного обновления или паузы автообновления.
2. **Гибкие режимы отображения**:
   - **Split View (50/50)**: экран разделен вертикально на две равные половины — слева TikTok, справа Instagram Reels.
   - **Отдельные страницы**: полноэкранная лента TikTok и Instagram с персональной статистикой.
   - **Сводная аналитика**: сравнение долей просмотров, средний ER и лидерборд трендовых звуков.
3. **Поиск и фильтрация**:
   - Полнотекстовый поиск по авторам, описаниям, трендовым трекам и хештегам.
   - Быстрый фильтр по клику на хештег.
   - 10 тематических ниш (ИИ и технологии, Юмор, Бизнес, Спорт, Танцы, Еда, Путешествия, Мода, Лайфстайл).
   - Сортировка: по рангу, просмотрам, темпу роста (velocity), вовлеченности (ER) и новизне.
4. **Комплексный экспорт аналитических отчетов**:
   - **.docx**: форматированный документ Microsoft Word со сводкой и детальной таблицей.
   - **.pdf**: презентабельный PDF-отчет со стилизованной шапкой и авто-таблицей.
   - **.txt**: компактный текстовый файл со всеми метриками.
5. **Интерактивный плеер**:
   - Клик по любой карточке открывает модальное окно с предпросмотром видео, деталями трека, автором и полным срезом виральности.

## Запуск проекта

### 1. Установка зависимостей
```bash
yarn install --ignore-engines
```

### 2. Запуск фронтенда
```bash
yarn dev
```
Фронтенд будет доступен по адресу `http://localhost:5173/`.

### 3. Запуск Fastify бэкенда
```bash
yarn server:dev
# или
cd server && npm run dev
```
API и стриминг-прокси будут доступны по адресу `http://localhost:3001/`.

## ⚡️ Бэкенд на Fastify (`server/`)
Бэкенд обеспечивает прямое взаимодействие с платформами (TikTok и Instagram) без хранения локальных медиафайлов:
- **`GET /api/proxy/video?url=...`**: Безопасный потоковый прокси видеопотоков (поддержка HTTP 206 Partial Content, Range requests, заголовков `Referer` и `User-Agent` платформ). Полностью исключает 403 Forbidden.
- **`GET /api/proxy/audio?url=...`**: Потоковый прокси аудиопотоков.
- **`GET /api/reels/trends`**: Каталог трендов с фильтрацией (страны, континенты, ниши) и пагинацией для ленивой подгрузки (lazy loading).
- **`GET /api/reels/resolve?url=...`**: Динамическое разрешение прямых потоков с оригинальных постов TikTok и Instagram.
- **`GET /api/music/search?q=...`**: Живой поиск музыкальных треков с аудио-превью.
